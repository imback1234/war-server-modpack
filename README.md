# War Server Modpack

The modpack for the War Server: a long-running survival war on Minecraft Java Edition 1.20.1 with Forge 47.4.10.
Guns, tanks, aircraft, craftable military armor, realistic terrain and far view distance.

## Download

**[War-Server-Modpack.zip](https://github.com/imback1234/war-server-modpack/releases/latest/download/War-Server-Modpack.zip)**
(the newest version is always at this link).

## Install with CurseForge

1. Open the CurseForge app, click **Minecraft**, then **My Modpacks**, then **Import**.
2. Click **Choose .zip file** and pick `War-Server-Modpack.zip`. Do not unzip it.
3. CurseForge warns that some files are not on CurseForge. Tick the box and click **All Files** (not "CurseForge Files Only").
4. Give the game at least 8 GB of memory: gear icon, **Minecraft**, **Allocated Memory** = `8192`.
5. Play the new **War Server** profile, then join the server from **Multiplayer**.

CurseForge downloads almost every mod from its own site. The zip only carries the files listed below.
